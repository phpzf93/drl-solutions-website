# Project Summary
DRL Solutions is a digital services company focused on delivering professional websites and mobile applications. The current project is a standalone web application built with React and TypeScript, functioning as an advanced e-commerce platform for acquiring digital products, including development tools and source code. Key features of the platform encompass user authentication, a shopping cart, and a checkout system that integrates with Supabase for backend services and Magpie.im for real-time payment processing. Recent enhancements have optimized the checkout process to ensure orders are finalized only after successful payment verification.

# Project Module Description
The project comprises the following functional modules:
- **Landing Page**: Overview of DRL Solutions and its offerings.
- **About Page**: Information on the company's mission, vision, and team.
- **Services Page**: Detailed list of professional services, including pricing and features.
- **Shop Page**: Showcase of digital products available for purchase with search and filter functionalities.
- **Checkout Page**: Handles user payments and order processing, integrated with Magpie.im for real-time payment.
- **Order Success Page**: Confirms successful transactions, providing download links and order details, along with automatic email receipts.
- **Account Page**: User profile management and order history viewing.
- **Admin Login Page**: Secure access to the admin dashboard.
- **Admin Dashboard**: Interface for managing products, orders, and sales analytics.
- **Privacy Policy Page**: Details on data collection and usage practices.
- **Refund Policy Page**: Conditions and processes for refunds.
- **Contact Page**: Inquiry form for business communications.

# Technology Stack
- **React**: JavaScript library for building user interfaces.
- **TypeScript**: Superset of JavaScript that adds static types.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Vite**: Build tool for modern web applications.
- **Shadcn/ui**: UI component library for consistent design.
- **React Router**: For routing and navigation.
- **TanStack Query**: For data fetching and state management.
- **Zustand**: State management library for React.
- **Supabase**: Backend as a service for database and authentication.
- **Magpie.im**: Payment processing service integrated into the checkout system for live transactions.
- **EmailJS**: Service for sending automated email receipts.
- **Framer Motion**: Library for animations and transitions.

# Usage
1. **Install Dependencies**: Run `pnpm install` to install all project dependencies.
2. **Linting**: Run `pnpm run lint` to check for code quality issues.
3. **Build the Project**: Run `pnpm run build` to build the project for production.
4. **Run the Project**: Use the command for your local development setup.
