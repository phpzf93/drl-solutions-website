# Project Summary
DRL Solutions is a digital services company that provides professional websites and mobile applications. This project is a standalone web application developed with React and TypeScript, functioning as a comprehensive e-commerce platform for purchasing digital products like development tools and source code. It features user authentication, a shopping cart, and a checkout system integrated with Supabase for backend services and Magpie.im for real-time payment processing. The platform supports secure payment options, including GCash, Maya, Alipay, WeChat Pay, credit/debit cards, and PayPal, ensuring a seamless user experience. Recent updates have enhanced the checkout process, ensuring that orders are only completed after successful payment verification.

# Project Module Description
The project includes the following functional modules:
- **Landing Page**: Introduces DRL Solutions and its services.
- **About Page**: Details the company's mission, vision, and team.
- **Services Page**: Lists the professional services offered, including pricing and features.
- **Shop Page**: Displays digital products for purchase with search and filtering options.
- **Checkout Page**: Manages user payment and order processing, integrated with Magpie.im for live payment.
- **Order Success Page**: Confirms successful transactions, providing download links and order details, and automatically sends email receipts.
- **Account Page**: Allows users to manage profiles and view order history.
- **Admin Login Page**: Provides secure access to the admin dashboard.
- **Admin Dashboard**: A comprehensive interface for managing products, orders, and sales analytics.
- **Privacy Policy Page**: Outlines data collection and usage practices.
- **Refund Policy Page**: Details conditions and processes for refunds.
- **Contact Page**: Provides a form for inquiries and business communications.

# Technology Stack
- **React**: JavaScript library for building user interfaces.
- **TypeScript**: Superset of JavaScript that adds static types.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Vite**: Build tool for modern web applications.
- **Shadcn/ui**: UI component library for consistent design.
- **React Router**: For routing and navigation.
- **TanStack Query**: For data fetching and state management.
- **Zustand**: State management library for React.
- **Supabase**: Backend as a service for database and authentication.
- **Magpie.im**: Payment processing service integrated into the checkout system for live transactions.
- **EmailJS**: Service for sending automated email receipts.
- **Framer Motion**: Library for animations and transitions.

# Usage
1. **Install Dependencies**: Run `pnpm install` to install all project dependencies.
2. **Linting**: Run `pnpm run lint` to check for code quality issues.
3. **Build the Project**: Run `pnpm run build` to build the project for production.
4. **Run the Project**: Use the command for your local development setup.
